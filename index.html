运营小结

图片存储 · 云盘

推荐坚果云 + Cloudflare Worker：不用 NAS / Docker，一个应用密码即可；出库凭证单独归档到 express-station/出库凭证/年-月/，入库照片放到 express-station/入库照片/年-月/，云盘里一眼可分。云盘接口必须由服务端中转（浏览器跨域会被拦），另一条路是阿里云盘 + AList WebDAV。凭据只填在这里和自己的 Worker / AList 后台，绝不写进公开仓库。GitHub Pages 是 https，WebDAV 地址也必须是 https。

用坚果云：三步就够

① 坚果云网页版 → 账户信息 → 安全选项 → 第三方应用管理 → 添加应用密码；② 把仓库里的 deploy/nutstore-worker.js 粘贴部署成 Cloudflare Worker（它只负责补 CORS 头，不用服务器）；③ 上面 WebDAV 地址填 Worker 根地址（结尾不要带 /dav），账号填坚果云邮箱，密码填应用密码，点「测试连接」。不要把 https://dav.jianguoyun.com/dav 直接填进来——坚果云不返回 CORS 头，浏览器会拦掉上传。免费版每月上传 1GB / 下载 3GB，照片量大就把「图片最长边」调到 1200 或升级专业版。若测试连接正常但上传报 409，先在坚果云网页端手工建好 express-station 文件夹，必要时再建 出库凭证 子目录。出库凭证只写这个目录，不会和入库照片混在一起。

仅桌面版 Chrome / Edge 支持，需 https 页面

使用说明与部署

查件（最常用）

顾客报手机号后四位或扫面单，在「查件」页输入即可看到货架位、在库天数，若已取走则显示取件人与出库时间；在库件可一键跳到「取件出库」并自动勾选。工作台顶部也有快速查件框。

日常流程

入库登记（可拍面单照）→ 包裹按货架位上架 → 取件时按后四位检索 → 拍照留证后确认出库。所有动作写入操作流水，误操作可撤销出库。

摄像头与拍照

「打开摄像头 / 拍取件凭证」会直接调用设备摄像头，可连拍、切换前后镜头；拍照后自动压缩并写入云盘。摄像头需要 https 页面（GitHub Pages 满足）并授权相机权限，用本地 file:// 打开或浏览器不支持时会自动回退到系统相机 / 相册。出库默认要求先拍照，可在「图片存储」里关闭。

数据在哪

默认保存在浏览器 localStorage，无需服务器、无需登录。开启 GitHub 同步后，台账会写入指定仓库的 JSON 文件；仓库建议设为私有，Pages 站点本身不要放任何令牌。

GitHub Pages

把本仓库推送到 GitHub 后，在 Settings → Pages 选择分支 main、目录 /（root）即可获得在线地址。纯静态，无构建步骤。

照片存云盘：坚果云（推荐）

入库照片写入 express-station/入库照片/年-月/（RK- 前缀），出库取件凭证写入 express-station/出库凭证/年-月/（CK- 前缀），文件名带拍摄时间，按日期就能在云盘里翻到凭证。坚果云不用 NAS：网页版生成应用密码 → 把 deploy/nutstore-worker.js 部署成 Cloudflare Worker → 在「图片存储」填 Worker 根地址 + 邮箱 + 应用密码。坚果云本身没有 CORS 头，直接填 dav.jianguoyun.com 会被浏览器拦，这个 Worker 就是补这一步。免费版每月上传 1GB / 下载 3GB；只拍出库凭证、把「图片最长边」设为 1200 更省额度。

照片存云盘：阿里云盘（AList）

用 deploy/docker-compose.yml 在 NAS 上启动 AList：管理 → 存储 → 添加 → 选「阿里云盘 Open」→ 刷新令牌填云盘 token、根文件夹 ID 填 root、WebDAV 策略选「本机代理」→ 在设置里开启 WebDAV。把 https://你的域名/dav 和管理员账号填进「图片存储」。AList 自带 CORS 头，但仍是 https：内网 http 地址会被 Pages 拦截，可用 Cloudflare Tunnel / Nginx 反代。

安全提醒

手机号只保留后四位。坚果云应用密码只存在本机浏览器、随请求头透传给自己的 Worker，Worker 代码里不写任何账号密码；云盘 token 只填 AList 后台。本机 deploy/.env 与 deploy/data/ 已被 .gitignore 排除，绝不提交到公开仓库。建议在 Worker 里配置 ALLOWED_ORIGINS / PROXY_KEY，避免地址泄露后被他人借用额度。
