帮助 / 关于
重建版 2.0.1 · 对照原「驿站助手」实现，明确排除通知类能力

      
已实现的功能

      
明确不做的功能

        
短信 / 电话 / 群呼属于通知类，按需求整块排除；其余需要服务端合作、实名资质或厂商 SDK 的能力，在纯静态本地版里无法真实实现，已在 README 中逐条写明替代方式。

      
数据与隐私

        
台账、客户、账号、设置、照片全部只存在当前浏览器（localStorage + IndexedDB），按站点来源隔离。换浏览器 / 换设备不会自动同步，请用「设置 → 数据备份」导出 JSON 再导入。清除浏览器数据会一并清掉，务必定期备份。
