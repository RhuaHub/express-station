运营小结

图片存储 · 阿里云盘

所有入库照片、出库取件凭证统一写入阿里云盘。阿里云盘接口只能由服务端调用，浏览器直连会被跨域拦截；请在 NAS / 本机用 AList（「阿里云盘 Open」驱动 + WebDAV）做中转。云盘 token 只填在 AList 后台，绝不写进本仓库或页面源码。GitHub Pages 是 https，WebDAV 地址也必须是 https。

仅桌面版 Chrome / Edge 支持，需 https 页面

使用说明与部署

日常流程

入库登记 → 包裹按货架位上架 → 取件时按手机后四位检索 → 勾选后确认出库。所有动作自动写入操作流水，误操作可在流水里撤销出库。

数据在哪

默认保存在浏览器 localStorage，无需服务器、无需登录。开启 GitHub 同步后，台账会写入指定仓库的 JSON 文件；仓库建议设为私有，Pages 站点本身不要放任何令牌。

GitHub Pages

把本仓库推送到 GitHub 后，在 Settings → Pages 选择分支 main、目录 /（root）即可获得在线地址。纯静态，无构建步骤。

照片存到阿里云盘

入库可拍面单 / 包裹照，出库可拍取件凭证，压缩后按「年-月」写入云盘的 express-station 目录。用 deploy/docker-compose.yml 在 NAS 上启动 AList：管理 → 存储 → 添加 → 选「阿里云盘 Open」→ 刷新令牌填云盘 token、根文件夹 ID 填 root、WebDAV 策略选「本机代理」→ 在设置里开启 WebDAV。最后把 https://你的域名/dav 和管理员账号填进「图片存储」。Pages 是 https，WebDAV 也必须是 https，否则浏览器会拦截混合内容；可用 Cloudflare Tunnel / Nginx 反代并开启跨域。

安全提醒

手机号只保留后四位。云盘 token 只填 AList 后台；本机 deploy/.env 与 deploy/data/ 已被 .gitignore 排除，绝不提交到公开仓库。凭据用完即清，建议定期轮换 token。
